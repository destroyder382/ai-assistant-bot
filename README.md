# AI Assistant Bot

Телеграм-бот на aiogram, который отвечает на сообщения через LLM API (Groq, бесплатный тариф) и помнит контекст диалога с каждым пользователем.

## Что умеет

- Отвечает на команду `/start`
- Отвечает на любой текст через языковую модель (openai-совместимый клиент, модель `openai/gpt-oss-120b` на Groq)
- Помнит историю переписки с каждым пользователем отдельно, в рамках текущего запуска
- Сохраняет историю в `histories.json` и подгружает её при следующем запуске — контекст не теряется после перезапуска

## Стек

- Python 3.14
- aiogram — работа с Telegram Bot API
- openai (клиент) + Groq — LLM API
- json — хранение истории диалогов

## Как запустить

1. Установить зависимости:
   ```
   pip install aiogram openai
   ```
2. Создать бота через [@BotFather](https://t.me/BotFather) в Telegram, получить токен
3. Получить бесплатный API-ключ на [console.groq.com](https://console.groq.com)
4. Создать файл `config.py` рядом с `bot.py`:
   ```python
   TOKEN = "токен_бота"
   GROQ_API_KEY = "ключ_groq"
   ```
   Файл `config.py` в `.gitignore` — он не должен попадать в репозиторий.
5. Запустить:
   ```
   python bot.py
   ```

Из России для доступа к Telegram API и Groq нужен VPN, включённый на уровне всей системы (не только браузера).
